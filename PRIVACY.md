# Confidentialité de Routix

Consultez la [politique publique](https://1337detailing.github.io/Routix/privacy.html) (19 octobre 2026).

- Parcours GPS, repères, préférences et journaux de diagnostic sont enregistrés localement.
- Les tuiles et styles en ligne utilisent OpenFreeMap / OpenMapTiles ; des coordonnées sont envoyées aux services OSM Overpass pour les informations routières, et à OSRM lorsqu’un itinéraire jusqu’au départ est demandé.
- GitHub peut être contacté pour les mises à jour.
- Aucune création de compte Routix, aucune publicité intégrée et aucune vente de données personnelles.
- Vous pouvez supprimer les parcours dans l’application ou effacer toutes les données dans les paramètres Android. Les sauvegardes système et les exports personnels sont gérés séparément.

Le formulaire « Sécurité des données » de Google Play doit être rempli d’après la version *réellement distribuée*, et réévalué à chaque évolution.
